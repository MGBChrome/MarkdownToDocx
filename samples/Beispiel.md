# Aus einer Idee wird ein Dokument

Dieses Beispiel zeigt, was **Markdown to Word** übernimmt: klare Überschriften,
*formatierte Texte*, Listen und Tabellen. Auch Umlaute wie ä, ö und ü bleiben erhalten.

## Alles an seinem Platz

- Markdown-Datei auswählen
- Speicherort prüfen
- In Word konvertieren und das Dokument öffnen

### Ein kleiner Überblick

| Funktion | Ergebnis |
| --- | --- |
| Überschriften | Strukturierte Abschnitte |
| Listen | Übersichtlich angeordnete Punkte |
| Tabellen | Editierbare Word-Tabellen |
| Links | Anklickbare Verweise |

> Gute Werkzeuge machen eine einfache Aufgabe angenehm.

## Ein bisschen Code

```csharp
var nachricht = "Hallo, Word!";
Console.WriteLine(nachricht);
```
